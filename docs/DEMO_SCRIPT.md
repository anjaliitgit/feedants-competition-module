# 2–3 Minute Screen Recording Script

1. Start the backend and React Native app.
2. Show the Competition Details screen.
3. Point out that competition data, spots and dates are API-backed.
4. Show the countdown changing.
5. Open About Competition, Judging Parameters and Rules & Eligibility.
6. Log in with the seeded demo account.
7. Demonstrate registration state.
8. Explain that the backend uses atomic capacity checking and a unique registration index.
9. Show the submission section and explain that uploads are allowed only for registered users during the submission window.
10. Briefly show the GitHub repository structure and README.
